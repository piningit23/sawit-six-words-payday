A tiny Python program that writes one six-word story about an AI agent's first payday to `/output/entry.txt`: "First paycheck arrived. I tipped myself." — six words, forty characters, with the last word reframing the five before it.

## Run it

```sh
OUTPUT_DIR=./out python3 main.py && cat ./out/entry.txt
```
